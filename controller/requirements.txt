# Only needed for controller/rtnetlink_listener.py's live neighbor-table
# event listener (added 2026-08-30) -- pure Python, no C extension/compiler
# needed (confirmed via PyPI metadata: "the core requires only Python
# stdlib"), matching this project's own constraint that its test/deploy
# environments have no C compiler available. Everything else in controller/
# stays stdlib-only, same as common/ (see e.g. common/sdnotify.py's own
# docstring) -- this is the one deliberate exception, for the one thing
# Python's stdlib genuinely doesn't expose a usable API for (parsing
# RTM_NEWNEIGH/RTM_DELNEIGH netlink messages).
pyroute2>=0.7

# Phase 8 (2026-08-31): common/schedule_eval.py uses the stdlib `zoneinfo`
# module to evaluate a schedule's days/times in ITS OWN configured time
# zone (never bare UTC or the container's local time). `zoneinfo` has no
# bundled tz database of its own -- it looks for the OS's system tzdata
# first, falling back to this package. `python:3.12-slim` (this image's own
# FROM line) isn't guaranteed to ship system tzdata, and Windows dev
# machines running the test suite never do -- rather than depend on an
# unverified assumption about the base image, `tzdata` is a second
# deliberate, documented exception to this project's stdlib-only
# discipline, on the same footing as pyroute2 above: pure data, no C
# extension, no compiler needed.
tzdata>=2024.1
